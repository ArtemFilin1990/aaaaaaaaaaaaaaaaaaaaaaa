# Этап 6. Корзина-заявка

## Ветка

`codex/request-cart`

## Цель

Создать B2B-корзину без оплаты: позиции, количества, срок, допустимость аналога, данные компании и безопасная серверная mock-отправка.

## Требования

- черновик сохраняется в браузере;
- корзина очищается только после подтверждённой отправки;
- серверная Zod-валидация;
- idempotency key;
- Bitrix24 остаётся в `mock`;
- лиды не используются;
- реальные внешние запросы запрещены;
- публичные цены отсутствуют;
- согласие на обработку данных обязательно.
