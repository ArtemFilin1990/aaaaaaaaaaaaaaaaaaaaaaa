# Задачи проекта

Папка содержит задания, которые запускаются по одному в мобильном режиме «Работа».

## Правила

- Не запускать несколько этапов одновременно.
- Перед задачей читать `AGENTS.md` и `docs/WORK_MODE.md`.
- Каждая задача выполняется в отдельной ветке.
- Следующий этап начинается только после публикации Pull Request либо сохранения экспортного пакета.
- Не считать локальный коммит опубликованным.

## Порядок

1. `01-baseline-stabilization.md` — стабилизация каркаса и CI.
2. Каноническая модель каталога.
3. Нормализация и поиск обозначений.
4. Каталог и фильтры.
5. Карточка товара и аналоги.
6. Корзина-заявка.
7. Bitrix24.
8. Импорт XLSX/CSV и подготовка 1С.
9. Главная страница и дизайн.
10. SEO, аналитика и база знаний.
11. Полный аудит и публикация.

Новые задачи создавать на основе `TASK_TEMPLATE.md`.
