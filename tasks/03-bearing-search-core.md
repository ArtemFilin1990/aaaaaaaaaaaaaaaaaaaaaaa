# Этап 3. Ядро поиска обозначений

## Ветка

`codex/bearing-search-core`

## Цель

Реализовать объяснимый серверный поиск подшипников по исходному обозначению, ГОСТ, ISO, алиасам и размерам.

## Обязательные запросы

- 205
- 6205
- 80205
- 180205
- 70-205
- 7205
- 6205-2RS-C3
- 6205 2RS C3
- 6205/2RS/C3
- 25×52×15

## Приоритет

1. исходное точное обозначение;
2. нормализованное точное обозначение;
3. точный алиас;
4. подтверждённое ГОСТ/ISO-соответствие;
5. номер и суффиксы;
6. префикс;
7. размеры;
8. название.

Результат обязан объяснять причину совпадения и не объявлять найденный товар инженерным аналогом автоматически.
