# Этап 4. Каталог, фильтры, сортировка и пагинация

## Ветка

`codex/stage-4-catalog-filters`

## Цель

Добавить серверный каталог с безопасными URL-фильтрами, сортировкой и стабильной пагинацией поверх PostgreSQL/Prisma.

## Границы

Входит: разбор query parameters через Zod, серверная выдача каталога, фильтры по основным техническим полям, сортировка без цены/наличия, пагинация, активные фильтры и состояние без результатов.

Не входит: цены, онлайн-оплата, реальные остатки, обещания сроков, клиентская панель администрирования.

## Критерии приёмки

- `/catalog` читает товары через repository layer.
- Фильтры отражаются в URL и не требуют клиентского JS для базового результата.
- Поддержаны q, бренд, категория, тип, ГОСТ, ISO, d/D/B, уплотнение, зазор, точность, сепаратор, материалы, единица и demo-статус.
- Некорректные параметры нормализуются безопасно.
- Пагинация имеет ограниченный page size и стабильный порядок.
- Сортировки не используют цену или наличие.

## Обязательные тесты

- `pnpm install --frozen-lockfile`

- `git diff --exit-code -- prisma/schema.prisma`
- `pnpm prisma:validate`
- `pnpm prisma:generate`
- `pnpm lint`
- `pnpm typecheck`
- `pnpm test`
- `pnpm build`
- `git diff --check`
- `pnpm test:integration`, если PostgreSQL доступна
- `pnpm test:e2e`, если браузер доступен

## Ограничения

- Совпадение размеров не подтверждает взаимозаменяемость.
- `supplyStatus` не показывается как реальное наличие.
- Prisma используется только на сервере.
