# ЭВЕРЕСТ — B2B-каталог подшипников

Новый проект полностью заменяет прежний Python-инструмент в ветке `main`. Старое состояние сохранено в ветке `archive/legacy-before-everest-store-2026-08-04` и в истории Git.

## Назначение

Сайт для поиска подшипников по ГОСТ, ISO, размерам и техническим параметрам, формирования корзины-заявки, первичного сохранения заявки в PostgreSQL и необязательной последующей серверной синхронизации через отключённый адаптер Bitrix24 без использования лидов.

Публичные цены, онлайн-оплата и неподтверждённое наличие не используются.

## Стек

- Next.js App Router
- TypeScript strict
- Tailwind CSS
- Prisma + PostgreSQL
- Zod
- Vitest
- Playwright
- Docker

## Разработка в режиме «Работа»

Основной канал разработки — мобильный режим «Работа».

Перед любой задачей агент обязан прочитать:

- `AGENTS.md`;
- `docs/WORK_MODE.md`;
- соответствующий файл из `tasks`.

Задачи выполняются по одной в отдельных ветках `codex/*`. Если GitHub-аутентификация в среде недоступна, агент создаёт локальные коммиты и экспортирует patch-файлы и архив по процедуре из `docs/WORK_MODE.md`. Локальные коммиты нельзя считать опубликованными без удалённой ветки или Pull Request.

Этап 1 завершён: стабилизирован каркас проекта и базовый CI.

Этап 2 добавил каноническую Prisma-модель каталога. Этап 2 считается закрытым только после фактической проверки PostgreSQL: чистый `migrate deploy`, повторный seed без дублей, DB verification и schema-drift check.

Этап 3 в работе: нормализация обозначений и PostgreSQL-backed поиск. Следующий этап после слияния: каталог, URL-фильтры, сортировка и пагинация.

Шаблон новых задач:

`tasks/TASK_TEMPLATE.md`

## Локальный запуск

```bash
cp .env.example .env
pnpm install
pnpm prisma:generate
pnpm dev
```

Откройте `http://localhost:3000`.

## Проверки

```bash
pnpm lint
pnpm typecheck
pnpm test
pnpm build
pnpm test:e2e
```

## Основные маршруты

## Безопасность

Реальные токены, вебхуки, `.env` и персональные данные запрещено коммитить. Заявка сначала должна сохраняться в PostgreSQL; Bitrix24 является отключённым будущим серверным адаптером и по умолчанию работает только в `mock`-режиме.
