# Интернет-магазин подшипников «ЭВЕРЕСТ»

Репозиторий переводится на новый проект: производственный B2B-каталог подшипников и промышленных комплектующих ООО «ЭВЕРЕСТ».

## Целевая модель сайта

Это не обычный розничный магазин. Основной сценарий:

**поиск → проверка характеристик → выбор количества → корзина-спецификация → заявка → сделка в Bitrix24 → коммерческое предложение менеджера.**

Планируемые возможности:

- поиск по ГОСТ, ISO, обозначению и размерам;
- каталог с техническими фильтрами;
- карточки подшипников;
- проверенные соответствия ГОСТ/ISO;
- контролируемая работа с аналогами;
- подбор по параметрам эксплуатации;
- загрузка спецификаций, фотографий и чертежей;
- B2B-корзина-заявка без онлайн-оплаты;
- серверная интеграция с Bitrix24 без лидов;
- импорт каталога из XLSX/CSV и подготовка интеграции с 1С;
- SEO-страницы и база знаний.

## Текущий статус

Репозиторий ранее содержал Python-скрипт для объединения дублей компаний в Bitrix24. Старые файлы пока не удалены. Первый промт требует провести аудит, зафиксировать миграцию и только после этого заменить рабочую структуру новым Next.js-проектом.

## Целевой стек

- Next.js App Router;
- TypeScript strict;
- Tailwind CSS;
- shadcn/ui или Radix UI;
- PostgreSQL;
- Prisma;
- Zod;
- React Hook Form;
- Vitest;
- Playwright;
- Docker.

## Безопасность

- реальные webhook, токены, пароли и `.env` не коммитить;
- интеграция Bitrix24 по умолчанию работает в mock/read-only;
- write-режим включается только отдельным флагом;
- лиды в Bitrix24 не используются;
- неподтверждённые цены, остатки, сроки, отзывы и статусы дилера не публикуются.
