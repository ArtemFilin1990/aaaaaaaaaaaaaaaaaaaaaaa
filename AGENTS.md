# AGENTS.md

## Цель

Разрабатывать B2B-каталог подшипников ООО «ЭВЕРЕСТ» для предприятий России и ЕАЭС.

## Обязательный стек

Next.js App Router, TypeScript strict, Tailwind CSS, Prisma/PostgreSQL, Zod, Vitest, Playwright, Docker.

## Бизнес-правила

- Не использовать публичные цены и онлайн-оплату.
- Не заявлять наличие или сроки без подтверждённых данных.
- Основная конверсия: поиск → карточка → корзина-заявка → сделка Bitrix24.
- Лиды в Bitrix24 не использовать.
- Интеграции выполнять только на сервере.
- Аналоги хранить со статусами DIRECT, ONE-WAY, PARTIAL, SIZE ONLY, NO DIRECT, CONFLICT.
- Доказательность аналогов: A, B, C, R.
- Совпадение размеров не означает прямую взаимозаменяемость.

## Каталог

Обязательные поля: наименование, артикул, ГОСТ, ISO, алиасы, бренд, тип, d, D, B/H, масса, зазор, точность, уплотнение, сепаратор, материалы, нагрузки, обороты, температура, статус поставки и документы.

## Дизайн

Инженерный премиальный B2B. Цвета: #111111, #F6F5F3, #C8C8C8, #F26A21, #223448. Минимум визуального шума, высокая читаемость технических данных.

## Качество

После каждого этапа запускать lint, typecheck, unit/integration tests и production build. Для пользовательских сценариев поддерживать Playwright E2E.

## Безопасность

Секреты только в env. Не печатать вебхуки и токены. Запись в Bitrix24 разрешать только при B24_MODE=write и B24_WRITE_ENABLED=true. По умолчанию mock.

## Работа с Git

Не переписывать историю без прямого распоряжения владельца. Делать логичные атомарные коммиты. Старый проект сохранён в архивной ветке.
