# Словарь данных каталога

Все значения текущего seed имеют статус `DEMO`. Они не подтверждают реальные остатки, сроки, сертификаты или дилерские полномочия.

## Product

Главная товарная сущность.

| Поле | Назначение |
|---|---|
| `slug` | стабильный URL товара |
| `sku` | внутренний уникальный ключ |
| `brandId`, `categoryId` | нормализованные связи |
| `bearingType` | конструктивный тип |
| `innerDiameterMm`, `outerDiameterMm`, `widthMm`, `heightMm` | размеры d, D, B/H |
| `clearance` | CN, C2, C3, C4, C5 |
| `precisionClass` | P0, P6, P5, P4 и другие |
| `seals` | открытый, Z/2Z, RS/2RS и варианты производителя |
| `cage` | материал и исполнение сепаратора |
| `supplyStatus` | нейтральный статус поставки без обещания наличия |
| `sourceStatus` | происхождение и проверенность записи |
| `isDemo` | признак учебных данных |

Поля публичной продажной цены в модели отсутствуют.

## ProductDesignation

Хранит исходное обозначение и отдельное нормализованное значение. Системы: `GOST`, `ISO`, `BRAND`, `INTERNAL`, `OTHER`.

Одинаковое текстовое значение может иметь разный смысл в разных системах. Пример: `7205` как ГОСТ и `7205` как ISO не должны автоматически объединяться.

## StandardMapping

Доказательная связь между двумя обозначениями. Содержит статус, уровень доказательности, источник и ручное подтверждение.

## AnalogRelation и AnalogEvidence

Связь товаров-кандидатов с обязательными статусами:

- `DIRECT`;
- `ONE_WAY`;
- `PARTIAL`;
- `SIZE_ONLY`;
- `NO_DIRECT`;
- `CONFLICT`.

Уровни доказательности: `A`, `B`, `C`, `R`. Совпадение d × D × B само по себе не даёт статус `DIRECT`.

## ImportBatch и ImportRow

Контур безопасного импорта. Исходная строка хранится в `rawData`, результат нормализации — в `normalizedData`, ошибки — в `errorMessages`. Импорт не удаляет отсутствующие в новом файле товары автоматически.
