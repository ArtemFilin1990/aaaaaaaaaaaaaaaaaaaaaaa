# Нормализация и ранжирование поиска

## Принцип

Поиск не изменяет исходный запрос пользователя. Для сопоставления дополнительно строятся:

- нормализованная строка;
- компактная строка без разделителей;
- базовый номер;
- суффиксы;
- размеры d × D × B, если запрос имеет размерный формат.

## Нормализация

Поддерживаются пробелы, дефисы, `/`, `_`, латинская `x`, кириллическая `х` и знак `×`.

Примеры:

- `6205 2RS C3` → `6205-2RS-C3`;
- `6205/2RS/C3` → `6205-2RS-C3`;
- `6205 ZZ` → `6205-2Z` как поисковая форма;
- `6205-2RSH-C3` → `6205-2RS-C3` как поисковая форма;
- `25×52×15` → размеры 25, 52 и 15 мм.

Поисковые алиасы не являются автоматическим инженерным подтверждением идентичности исполнений разных производителей.

## Ранжирование

1. точное исходное обозначение;
2. точное нормализованное обозначение;
3. точный алиас;
4. подтверждённое соответствие ГОСТ/ISO;
5. базовый номер и часть суффиксов;
6. префикс;
7. размеры;
8. наименование.

Каждый результат возвращает причину совпадения, совпавшее значение и техническое предупреждение для приблизительных результатов.

## Неоднозначность 7205

`7205` должно возвращать как минимум два возможных смысла при наличии данных:

- ГОСТ 7205 → ISO 30205, конический роликовый;
- ISO 7205, радиально-упорный шариковый.

Система обозначения обязательна для технического заключения.

## Граница ответственности

Поиск выдаёт кандидатов. Он не присваивает статус аналога. Инженерная взаимозаменяемость определяется отдельно через `AnalogRelation` и доказательные источники.
