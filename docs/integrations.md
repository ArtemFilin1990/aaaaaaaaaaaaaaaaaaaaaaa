# Интеграции

## Bitrix24

Режимы: `mock`, `read-only`, `write`. По умолчанию `mock`. Запись разрешается только при одновременных `B24_MODE=write` и `B24_WRITE_ENABLED=true`, но реальный write-адаптер пока не реализован.

Текущий endpoint `POST /api/request`:

- принимает только JSON;
- валидирует заявку через Zod;
- требует UUID idempotency key;
- работает только при `B24_MODE=mock` и `B24_WRITE_ENABLED=false`;
- возвращает номер `MOCK-*`;
- не выполняет сетевые запросы к Bitrix24;
- при попытке включить другой режим возвращает 503.

План реального адаптера: найти компанию по ИНН, контакт по телефону/e-mail, создать или связать сущности, затем создать сделку без лида. Добавить долговременный idempotency key, rate limiting, маскирование логов и контролируемые повторы.

Подробно: `docs/request-flow.md`.

## 1С

Прямое подключение не выполняется до утверждения схемы обмена. Первый этап — контролируемый CSV/XLSX импорт с предпросмотром, отчётом конфликтов и откатом партии.

## Хранилище файлов

Спецификации и чертежи должны проходить проверку MIME, расширения и размера. Секретные ссылки не должны попадать в клиентские логи.
