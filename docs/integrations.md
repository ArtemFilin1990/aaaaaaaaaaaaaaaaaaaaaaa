# Интеграции

## Bitrix24

Режимы: `mock`, `read-only`, `write`. По умолчанию `mock`. Запись разрешена только при одновременных `B24_MODE=write` и `B24_WRITE_ENABLED=true`.

План: найти компанию по ИНН, контакт по телефону/e-mail, создать или связать сущности, затем создать сделку без лида. Добавить idempotency key, rate limiting, маскирование логов и серверную валидацию.

## 1С

Прямое подключение не выполняется до утверждения схемы обмена. Первый этап — контролируемый CSV/XLSX импорт с предпросмотром, отчётом конфликтов и откатом партии.

## Хранилище файлов

Спецификации и чертежи должны проходить проверку MIME, расширения и размера. Секретные ссылки не должны попадать в клиентские логи.
