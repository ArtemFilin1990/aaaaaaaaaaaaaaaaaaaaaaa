# Интеграции

## Текущая версия

Сайт работает автономно. Заявки не передаются в Bitrix24, CRM, e-mail, Telegram, webhook или другие внешние системы.

Активная конфигурация:

```env
CRM_MODE=disabled
ORDER_NOTIFICATION_MODE=disabled
```

## CRM

В проекте существует только архитектурный интерфейс `CrmAdapter` и реализация `DisabledCrmAdapter`.

`DisabledCrmAdapter`:

- возвращает `isEnabled() = false`;
- не выполняет `fetch`;
- не открывает сетевые соединения;
- не использует webhook и токены;
- возвращает статус `DISABLED`;
- не мешает успешному сохранению заявки.

Неизвестное значение `CRM_MODE` считается ошибкой конфигурации и не включает внешнюю интеграцию.

## Уведомления

Внешние уведомления отключены. Пользователю сообщается только факт сохранения заявки и её номер. Нельзя утверждать, что менеджер получил уведомление.

## Будущие интеграции

CRM, почта, Telegram, 1С и другие системы могут быть добавлены позже отдельными серверными адаптерами после утверждения требований, безопасности и тестов. Они не входят в текущий scope.
