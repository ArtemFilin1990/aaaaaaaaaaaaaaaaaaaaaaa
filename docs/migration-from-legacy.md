# Миграция со старого проекта

## Исходное состояние

До 4 августа 2026 года ветка `main` содержала Python-скрипт для безопасного объединения дублей компаний Bitrix24 по ИНН, его документацию и служебные файлы.

## Решение

По прямому распоряжению владельца ветка `main` полностью переведена на новый B2B-каталог подшипников. История Git не переписана.

## Сохранение старого проекта

Состояние перед миграцией сохранено:

- в истории Git, последний коммит старого состояния: `5c1812c7ed1f95191c95b49a7b518b263279ce80`;
- в ветке `archive/legacy-before-everest-store-2026-08-04`.

## Удалено из нового дерева

Python-скрипты, конфигурации и документация, относящиеся только к очистке дублей Bitrix24. Они остаются доступными в архивной ветке.

## Целевая структура

- `src/app` — маршруты Next.js;
- `src/components` — интерфейсные компоненты;
- `src/data` — демонстрационные данные;
- `src/lib` — доменная логика и адаптеры;
- `prisma` — схема PostgreSQL;
- `tests` — unit и E2E;
- `docs` — решения и регламенты;
- `prompts` — последовательность заданий Codex.

## Риски

- Демонстрационный каталог не является рабочим прайсом или складским остатком.
- Реальная интеграция с Bitrix24 пока не включена.
- Миграции PostgreSQL и lock-файл должны быть сформированы после установки зависимостей.
