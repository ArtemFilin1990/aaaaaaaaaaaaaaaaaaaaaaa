# Словарь данных каталога

Этап 2 фиксирует каноническую модель каталога без публичных цен, онлайн-оплаты, подтверждённых остатков и сроков поставки.

## Основные сущности

| Сущность | Назначение |
| --- | --- |
| `Product` | Техническая карточка изделия: тип, размеры `d`, `D`, `B/H`, единицы, масса, зазор, точность, уплотнение, сепаратор, материалы, нагрузки, обороты, температуры и безопасный статус поставки. |
| `ProductDesignation` | Раздельное хранение внутреннего артикула, обозначения производителя, ГОСТ и ISO с исходной (`rawValue`) и нормализованной (`normalizedValue`) формой. |
| `Brand` | Производитель или демонстрационный бренд каталога. |
| `Category` | Иерархическая категория изделия. |
| `ProductAttribute` | Расширяемые технические атрибуты без изменения базовой схемы. |
| `StandardMapping` | Привязка изделия к стандарту (`GOST`, `ISO`, `DIN`, `SKF`, `MANUFACTURER`, `INTERNAL`) с исходным и нормализованным кодом. |
| `AnalogRelation` | Направленная связь аналогов со статусом `DIRECT`, `ONE_WAY`, `PARTIAL`, `SIZE_ONLY`, `NO_DIRECT` или `CONFLICT`. |
| `AnalogEvidence` | Источник доказательности аналога с уровнем `A`, `B`, `C` или `R`. |
| `TechnicalDocument` | Метаданные паспортов, чертежей, сертификатов и спецификаций. |
| `SearchAlias` | Поисковые синонимы и распространённые обозначения, отделённые от канонических обозначений. |
| `ImportBatch` | Партия импорта с контрольной суммой и статусом обработки. |
| `ImportRow` | Строка импорта с исходными и нормализованными данными, статусом и ссылкой на продукт. |

## Правила обозначений

- ГОСТ, ISO, внутренний артикул и обозначение производителя не объединяются в одно поле.
- Исходная форма обозначения сохраняется для аудита, нормализованная форма используется для уникальности и будущего поиска.
- Совпадение `d × D × B/H` допускается хранить как факт размера, но не делает товары прямыми аналогами.

## Автономная модель заявки

Заказ/заявка на будущих этапах должен сохраняться в PostgreSQL как автономная запись приложения. Bitrix24 остаётся отключённым будущим серверным адаптером; запись во внешнюю CRM запрещена без явных `B24_MODE=write` и `B24_WRITE_ENABLED=true`.
